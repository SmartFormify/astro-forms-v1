# Astro Event Registration Form

An event-registration template that submits a normal HTML POST to a hosted SmartFormify endpoint. It intentionally does not create accounts or collect passwords.

Set `endpointUrl` in `src/registration.astro` to `https://api.smartformify.com/fe/YOUR_ENDPOINT_KEY`, then move the page and stylesheet into an Astro project. The root project provides the maintained, runnable template library and tutorials.
