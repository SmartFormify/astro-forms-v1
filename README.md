# Astro Forms v1

A collection of reusable **Astro form examples** designed to submit form data directly to **SmartFormify**.

This project is intended for a blog and example repository where developers can copy an Astro form, connect it to a SmartFormify endpoint, and start receiving form submissions without building a custom form-processing backend or Astro API route.

## Why Use SmartFormify?

SmartFormify lets your website forms submit data to a hosted form endpoint instead of requiring you to build and maintain your own form-processing backend.

With this approach:

- Keep your Astro project focused on frontend form UI.
- Avoid creating a custom Astro API route for every form.
- Submit forms directly to a SmartFormify endpoint.
- Reuse the same endpoint-based integration pattern across forms.
- Manage submissions and post-submission behavior through SmartFormify.
- Keep form examples lightweight and easy to deploy.

The basic integration is:

```text
Astro Form
    ↓
SmartFormify Endpoint
    ↓
Submission Processing
```

## How to Sign Up

1. Open the SmartFormify website.
2. Create a SmartFormify account.
3. Sign in to the dashboard.
4. Create or configure a form endpoint.
5. Copy the endpoint URL.
6. Add the endpoint URL to your Astro form.
7. Submit a test form.

> Dashboard labels and signup steps may change. Follow the current SmartFormify dashboard instructions when creating your account or endpoint.

## How to Create an Endpoint URL

After signing in to SmartFormify:

1. Open your dashboard.
2. Create a new form/endpoint.
3. Configure the endpoint for your form.
4. Configure any required domain/security settings.
5. Copy the endpoint URL generated by SmartFormify.

Use it as the form's `action`:

```html
<form
    action="YOUR_SMARTFORMIFY_ENDPOINT_URL"
    method="POST"
>
```

Replace `YOUR_SMARTFORMIFY_ENDPOINT_URL` with your actual endpoint.

## How to Use the Endpoint in Astro

The Astro examples use frontmatter:

```astro
---
const endpointUrl = "YOUR_SMARTFORMIFY_ENDPOINT_URL";
---
```

Then:

```astro
<form action={endpointUrl} method="POST">
    <!-- form fields -->

    <button type="submit">
        Submit
    </button>
</form>
```

This keeps the endpoint easy to update.

### Complete Example

```astro
---
const endpointUrl = "YOUR_SMARTFORMIFY_ENDPOINT_URL";
---

<form action={endpointUrl} method="POST">
    <div class="form-group">
        <label for="name">Name</label>
        <input
            type="text"
            id="name"
            name="name"
            required
        />
    </div>

    <div class="form-group">
        <label for="email">Email</label>
        <input
            type="email"
            id="email"
            name="email"
            required
        />
    </div>

    <div class="form-group">
        <label for="message">Message</label>
        <textarea
            id="message"
            name="message"
            required
        ></textarea>
    </div>

    <input
        type="hidden"
        name="notes_hqse"
        value=""
    />

    <button type="submit">
        Send Message
    </button>
</form>
```

## SmartFormify Hidden Field

Keep this field in every form:

```html
<input
    type="hidden"
    name="notes_hqse"
    value=""
/>
```

Important:

- Keep the name exactly `notes_hqse`.
- Keep the value empty.
- Do not remove the field.
- Do not add normal validation to this field.

## After Submission

SmartFormify can be configured for post-submission behavior.

Depending on the configured workflow, SmartFormify can provide a response such as a redirect URL or thank-you content.

Configure the desired after-submission behavior in SmartFormify rather than adding a separate backend to each Astro example.

## Domain and Security Settings

If your SmartFormify endpoint uses domain allowlisting or other security controls, configure the domain where the Astro form is hosted.

For local development, allow the exact origin used by your Astro development server, such as:

```text
http://localhost:4321
```

For production, configure your deployed website domain as required by the endpoint.

## File Upload Forms

The **Contact Form with File Upload** example is intended for file-upload submissions.

Make sure the SmartFormify endpoint is configured for the upload workflow and that the HTML form uses the encoding required by the endpoint when files are submitted.

## Project Structure

Each form follows a simple structure:

```text
form-name/
├── README.md
├── src
    ├── style.css
    └── form_name.astro
```

The `.astro` file contains the form.

`style.css` contains the styling.

The individual `README.md` explains the form.

## Using a Form in Astro

1. Copy the desired form folder into your Astro project.
2. Put the `.astro` file under an appropriate `src/pages/` location.
3. Place the CSS where the stylesheet reference can load it.
4. Configure your SmartFormify endpoint.
5. Review field names and required fields.
6. Run the Astro project.
7. Submit a test form.
8. Verify the submission in SmartFormify.

No custom Astro API route is required for the basic endpoint submission flow.

## Testing Checklist

- [ ] SmartFormify account is configured.
- [ ] Endpoint URL is correct.
- [ ] Website domain is allowed if required.
- [ ] Form uses `method="POST"`.
- [ ] Fields have meaningful `name` attributes.
- [ ] Required fields use `required` where appropriate.
- [ ] `notes_hqse` exists and is empty.
- [ ] File upload settings are correct for upload forms.
- [ ] Form works on desktop.
- [ ] Form works on mobile.
- [ ] Test submission reaches SmartFormify.
- [ ] After-submission behavior works as expected.

## Project Goal

**Astro Forms v1** provides simple, reusable Astro form examples for websites that use **SmartFormify as the form submission endpoint**.

The examples focus on:

```text
Astro UI
+
External CSS
+
SmartFormify Endpoint
```

This keeps the forms lightweight and avoids unnecessary backend code for each example.
